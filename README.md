# 🛒 Caixa de Mercado

Projeto desenvolvido para a disciplina de Projeto Integrador. Consiste em um sistema simples de caixa de mercado rodando direto no navegador.

## 📌 Funcionalidades
- Cadastro simples do nome do cliente.
- Escolha de produtos e quantidades via prompt.
- Desconto automático de 5% para compras acima de R$ 100,00.
- Opções de pagamento: Dinheiro (com cálculo de troco), Cartão ou Pix.
- Exibição do resumo final da compra na tela estilizado com Bootstrap.

## 🛠️ Tecnologias
- HTML5
- JavaScript
- Bootstrap 5

## 🚀 Como rodar
Apenas acesse o arquivo [`MercadinhoDaVila`](./index.html) em qualquer navegador.
